    📡 Heltec V4 (Meshtastic)

    Подключи Heltec к WiFi через приложение Meshtastic (Module Config → MQTT/HTTP/WiFi). Узнай IP в том же приложении или на роутере. Порт по умолчанию 4403.

    ⚠️ Предупреждения о погоде

    Раз в N минут бот проверяет прогноз. При выполнении любого условия — шлёт алерт в mesh (один раз в сутки на тип). Безопасный спам-фильтр: даже если условия держатся весь день, каждое предупреждение придёт максимум один раз за календарные сутки.

    Несколько слотов с собственным набором полей. Например: 08:00 — короткая сводка, 21:00 — прогноз на завтра (утро и вечер).

    Режим работы
    
            
    
              
              
            
    

            
            
    
              
    Авторизация (одноразово, через SSH)
    
              
    
                1. Возьми api_id и api_hash на
                my.telegram.org → API development tools.
    
                2. Сохрани их ниже, нажми «Сохранить».
    
                3. На Pi через SSH запусти один раз:
                cd /home/pi/weather-mesh-bridge && source .venv/bin/activate && python telegram_setup.py
    
                Введи телефон + SMS-код (и 2FA пароль если включён). Сессия сохранится.
              
    
              
    
                
                
              
    
            
    

            
    Прокси (если t.me у твоего провайдера зарезано)
    
            
    
              Формат URL. Примеры:
    
              socks5://127.0.0.1:1080 — локальный SOCKS5 (например, от ssh -D)
    
              socks5://user:pass@1.2.3.4:1080 — удалённый с авторизацией
    
              http://1.2.3.4:8080 — обычный HTTP-прокси
    
              Пусто — ходить напрямую без прокси.
            
    
            
    
              
              
            
    
            
    

            
    Каналы для прослушки
    
            
    По одному в строке. В режиме «Без API» — только @username публичных каналов.
    
            

            
    Ключевые слова
    
            
    Через запятую. Совпадение по подстроке, без учёта регистра. Хотя бы одно слово должно быть в сообщении.
    
            

            
    Гео-фильтр (опционально — сужает алерты до твоего региона)
    
            
    
              Если задан — сообщение должно содержать и ключевое слово, и хотя бы одно из этих.
              Пусто — пропускать любой матч по ключевым словам.
    
              Пример: Чувашия, Чебоксары, Татарстан, Марий Эл, Нижний Новгород
            
    
            

            
    Куда транслировать в mesh
    
            
    Найденные сообщения уйдут в этот канал Meshtastic и этому адресату.
    
            
    
              
              
            
    

            
    
              
              
              
            
    

            
            
            
            
    
              📦 Хочешь супер-короткое сообщение? Очисти поле «Префикс в mesh-сообщении» (станет: @username\n<текст>),
              а если ещё и снять галку выше — пойдёт только сам текст без всякой обвязки.
            
    

            
    Чёрный список фраз (удаляются полные строки)
    
            
    
              По одной фразе в строке. Если в сообщении найдётся хотя бы одна — вся строка вычищается из mesh-пакета.
              Регистр не важен. Для регулярных выражений начни строку с re:.
    
              Примеры: Обход белых списков, @Internet_Boost_bot, Подписаться:, re:наш\s+(чат|тг|канал)
            
    
            

            
    Защита от спама (промо-постов в формате «алерта»)
    
            
    
              Каналы любят прятать рекламу/призывы в посты-«алерты» (типа «ТРЕВОГА» + список 80 городов с @username). Эти лимиты сразу режут такое.
