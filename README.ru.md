# Weather → Heltec Mesh Bridge

[🇬🇧 English](README.md) · 🇷🇺 Русский

Бот для Raspberry Pi, который по расписанию рассылает сводки погоды в Meshtastic mesh-сеть через Heltec Mesh Node V4. С современным glass-UI, картой узлов, визуализацией traceroute и полной настройкой Heltec прямо в браузере.

## Возможности

- 🌍 **Погода** — Open-Meteo (без API-ключа): прогноз, качество воздуха, УФ-индекс, температура воды
- 📡 **Связь с Heltec** — USB-кабель или WiFi (TCP) через официальную Python-библиотеку `meshtastic`
- 🎨 **Glass-веб-UI** с четырьмя вкладками:
  - 📊 **Главная** — статистика: связь с Heltec, количество узлов, RSSI, hops, сообщения за сутки
  - 🗺 **Карта** — Leaflet-карта всех узлов с координатами, плюс наложение traceroute
  - ⚙️ **Настройки** — город, стиль сообщения, подключение Heltec, алерты погоды, расписание, ручная отправка
  - 💬 **Чат** — мессенджер с каналами и DM, реакциями, ответами, индикаторами доставки и RF-метаданными
- ⚙️ **Управление Heltec из браузера** — смена длинного/короткого имени, региона LoRa, роли, hop limit, modem preset, TX power, перезагрузка ноды
- 🛰 **Traceroute** — измерь путь до любого узла, увидь и прямой, и обратный маршрут с SNR, нарисуй его на карте (красные стрелки туда, синие обратно)
- ✓✓ **Индикаторы доставки** в чате (☁ отправлено / ✓✓ доставлено / ⚠ ошибка) — DM запрашивают ACK, статус обновляется в реальном времени
- ⚠️ **Алерты погоды** — гроза, сильный ветер, дождь, **мороз**, **жара** — дедупликация раз в сутки
- ⏰ **Расписание** — APScheduler с cron-триггерами, любое количество слотов со своим набором полей, днями недели и часовым поясом
- 📡 **Авточанкование** — длинные сообщения автоматически режутся на куски `(i/N)` с настраиваемой паузой
- 🛠 **Автозапуск systemd** одной командой
- 🔒 **HTTPS из коробки** с самоподписанным сертификатом (браузерные уведомления работают даже в локальной сети)

## Что внутри сообщения

Поля выбираются независимо для каждого слота:

- 🌡 Температура + состояние неба
- 🤔 Температура по ощущению
- 📊 Сравнение со вчера (`на 3°C теплее` / `на 2°C холоднее`)
- 🌊 Температура воды (Marine API для прибрежных координат; оценка по 7-дневной средней температуре воздуха для рек/озёр, с префиксом `≈`)
- 💧 Влажность
- ⏲ Давление (мм рт.ст.)
- 💨 Ветер (м/с + направление + порывы)
- 🌧 Осадки
- 🌫 Качество воздуха (европейский AQI + PM2.5 + PM10)
- ☀️ УФ-индекс (с риском по шкале)
- 📅 Прогноз на сегодня (мин/макс + вероятность дождя)
- 🌅 Завтра: утро (09:00) и вечер (21:00)

Смайлики — отдельный тумблер. Так же есть тумблер «Заголовок» (`Погода — Город`). Пример без смайликов:

```
Погода — Москва
+3.4°C, переменная облачность
Ощущается как +0.8°C
на 5°C холоднее, чем вчера
влажность 78% · давление 750.2 мм рт.ст.
ветер 4.2 м/с З (порывы 8)
сегодня -1…+5°C · небольшой дождь · вероятность осадков 60%
Завтра · +5…+14°C · в основном ясно
утро +7°C переменная облачность 10% · вечер +11°C в основном ясно
```

## Что нужно

- Raspberry Pi 4 (или любая Linux-машина с Python 3.10+)
- Heltec Mesh Node V4 (или совместимая Heltec-плата) с прошивкой Meshtastic
- WiFi-роутер или USB-кабель, чтобы соединить их

## Установка на Raspberry Pi

> При первом запуске бот сам создаст `config.json` из дефолтов. Если хочешь заведомо чистый конфиг — скопируй пример:
> ```bash
> cp config.example.json config.json
> ```
> Дальше всё настраивается через веб-UI и сохраняется в `config.json`.

1. Прошей Heltec V4 фирмварём Meshtastic ([гайд](https://meshtastic.org/docs/getting-started/flashing-firmware/heltec/)) и подключи к Pi по USB (или потом настрой WiFi).
2. Клонируй проект на Pi:
   ```bash
   git clone https://github.com/Vexorter42/weather-mesh-bridge.git /home/pi/weather-mesh-bridge
   cd /home/pi/weather-mesh-bridge
   ```
3. Запусти установщик:
   ```bash
   bash install.sh
   ```
   Он создаст venv, поставит зависимости и добавит пользователя в группу `dialout` (нужно перелогиниться или перезагрузиться).
4. Проверь, что устройство видно:
   ```bash
   ls /dev/ttyUSB* /dev/ttyACM*
   ```
   Должно появиться что-то вроде `/dev/ttyUSB0`.
5. Запусти руками для теста:
   ```bash
   source .venv/bin/activate
   python app.py
   ```
6. Открой `https://<ip-pi>:5000` с любого устройства в той же сети.
   При первом запуске бот сгенерирует самоподписанный сертификат, и браузер
   ругнётся «Подключение не защищено» — нажми **«Дополнительно → Перейти на сайт»**
   один раз, дальше он запомнит. Чтобы отключить HTTPS и работать по простому HTTP,
   запусти с `WMB_HTTPS=0 python app.py` (или поправь systemd-юнит).

## Автозапуск (systemd)

```bash
sudo cp weather-mesh-bridge.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now weather-mesh-bridge
sudo journalctl -u weather-mesh-bridge -f   # смотреть логи
```

Если у тебя другое имя пользователя или путь — поправь `weather-mesh-bridge.service`.

## Использование UI

### 📊 Вкладка «Главная»

Сводка в реальном времени:

- Статус связи с Heltec, выбранное направление, последний путь
- Сколько узлов известно / уникальных отправителей за сутки / всего сообщений
- За 24 часа: **отправлено** / **получено** / **средний RSSI** / **среднее число hops**
- Последняя активность mesh-сети — время последнего входящего и исходящего
- Список узлов — клик по любому открывает профиль (телеметрия, позиция, действия)

### 🗺 Вкладка «Карта»

Leaflet-карта со всеми узлами, у которых есть координаты. Клик по маркеру — попап с краткой информацией; ссылка «Открыть профиль» открывает ту же модалку, что и список на главной. После traceroute поверх карты рисуется маршрут:

- 🔴 Красная сплошная линия со стрелками — путь запроса (туда)
- 🔵 Синяя пунктирная линия со стрелками — путь ответа (обратно)
- 🛰 Зелёный пин — твой бот
- 🎯 Жёлтый пин — получатель
- Синие нумерованные пины — ретрансляторы

### ⚙️ Вкладка «Настройки»

1. **Город** — введи название на любом языке, выбери из списка. Координаты и часовой пояс подставятся.
2. **Стиль сообщения** — переключатели смайликов, заголовка `Погода — Город` и ответов на команды в чате (`/погода`, `/ping`, `/nodes`, `/help`).
3. **Heltec V4** — тип подключения:
   - **USB-кабель** — `auto` находит устройство сам.
   - **WiFi (TCP)** — IP и порт (по умолчанию 4403).
   - **Пауза между чанками** — пауза между частями длинного сообщения.
   - **Проверить связь** — активно открывает соединение и показывает точную ошибку.
   - **⚙️ Настройки Heltec** — открывает модалку, где можно сменить длинное/короткое имя ноды, регион LoRa, роль, hop limit, modem preset, TX power и перезагрузить устройство — всё без приложения Meshtastic.
4. **Предупреждения о погоде** — пороги для грозы / ветра / дождя / **мороза** / **жары** с дедупликацией на день (один алерт каждого типа в сутки).
5. **Расписание** — слоты с временем, часовым поясом, днями недели и набором полей. Изменения сохраняются автоматически. Под слотом — «следующий запуск».
6. **Отправить сейчас** — мгновенный ручной тест. Кнопка «Предпросмотр» строит сообщение без отправки.

### 💬 Вкладка «Чат»

Двухпанельный мессенджер:

- **Сайдбар** — все каналы + все DM-собеседники, со счётчиками непрочитанного и превью последнего сообщения.
- **Основная панель** — баблы с аватарами, ответы, реакции (длинное нажатие → эмодзи в приложении Meshtastic), RF-метаданные для входящих (hops · RSSI · SNR, цветовая подсветка).

У исходящих сообщений рядом со временем теперь индикатор доставки:

| Иконка | Что значит |
|---|---|
| ☁ | **Отправлено в эфир** — пакет ушёл, ACK пока не пришёл |
| ✓✓ | **Доставлено** — получатель прислал ACK (только DM). При наведении: «ACK через N hops» |
| ⚠ | **Ошибка** — Routing вернул сбой |

Бот отвечает на команды в чате, если включено в настройках: `/погода`, `/ping`, `/nodes`, `/help` (и `!` тоже работает префиксом).

## Решение проблем

- **`Permission denied: '/dev/ttyUSB0'`** — пользователь не в группе `dialout`. Добавь и перезагрузись:
  `sudo usermod -aG dialout $USER && sudo reboot`
- **`Не найдено USB-устройство Heltec`** — проверь кабель (часто бывают «только зарядка»), `lsusb` и `dmesg | tail` после подключения. Heltec V4 обычно регистрируется как CP210x или CH9102.
- **`No route to host` через WiFi** — Heltec получил другой DHCP-адрес, либо в роутере включена client/AP-изоляция. Закрепи IP Heltec в DHCP-таблице роутера.
- **`Data payload too big`** — бот теперь сам режет длинные сообщения, но если всё равно ловишь ошибку — убери одно поле из слота или сократи название города.
- **Расписание не сработало** — открой `/api/scheduler/jobs` в браузере, посмотри `next_run`. Скорее всего бот был оффлайн ровно в этот момент (дефолтный misfire grace 1 час покрывает короткие перезапуски).
- **Неверное время отправки** — проверь часовой пояс в слоте, потом `timedatectl` на Pi (часы должны быть синхронизированы).
- **Индикатор доставки застрял на ☁** — только DM получают сквозной ACK; broadcast'ы останутся с ☁ навсегда — это нормально. Для DM, если ☁ висит больше ~30 сек, получатель скорее всего оффлайн или недоступен.
- **Traceroute таймаутит** — получатель может быть в нескольких hops в нестабильной сети. Увеличь `hop_limit` или попробуй ещё раз; LoRa медленный, ACK может идти 15–30 секунд.
